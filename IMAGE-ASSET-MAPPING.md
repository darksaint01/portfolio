# Portfolio asset mapping

This update uses **Projects Images.zip** to replace the existing Roblox/Mobile artwork, add Allied Fusion website captures, and rebuild the graphic design collections. Original folder associations have been preserved as logical destination paths.

**GMT exception:** the supplied image ZIP does not contain a GMT/System folder, so the 5 original GMT screenshots in `public/projects/gmt-*.png` from the provided latest portfolio were retained. No unrelated artwork was substituted. Other projects without supplied imagery remain text-only to avoid misrepresenting the work.

All images were converted to high-quality WebP with aspect ratios preserved and no crop. Larger source images were downsampled for manageable browser loading. The gallery provides a "View full image" action for inspecting large/portrait designs in a separate tab. Composite cover images were assembled without cropping from source files in the same category; individual source visuals are in their corresponding galleries.
